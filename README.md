# AOTH · ΑΟΘ Γ΄ Λυκείου · Κεφάλαια 1–5

Διαδραστικό μάθημα για τις Αρχές Οικονομικής Θεωρίας:

- Σελίδα για κάθε κεφάλαιο (1–5): σε απλά λόγια, πραγματικά παραδείγματα, λυμένα βήμα-βήμα, ασκήσεις Α/Β/Γ με λύσεις
- Εργαστήρια: ΚΠΔ, ζήτηση & ελαστικότητα, παραγωγή & κόστος, προσφορά, αγορά & ισορροπία (ανώτατη/κατώτατη τιμή)
- Γεννήτρια 22 τύπων ασκήσεων με αυτόματο έλεγχο, quiz 83 ερωτήσεων
- PDF μαθητή/καθηγητή ανά κεφάλαιο στον φάκελο `pdf/`

Στατικό site (ένα `index.html`), χωρίς build.
