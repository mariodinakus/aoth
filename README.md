# ΑΟΘ · Μάθημα 1 · Κεφάλαια 1 & 2

Διαδραστικό μάθημα για τις Αρχές Οικονομικής Θεωρίας (Γ΄ Λυκείου):

- Εργαστήριο ΚΠΔ & κόστους ευκαιρίας (κλικ πάνω στο διάγραμμα, «ταξίδι» πάνω στην καμπύλη)
- Εργαστήριο ζήτησης & ελαστικότητας (sliders, ΣΔ ως εμβαδόν, ΣΔ ως προς την τιμή)
- 7 λυμένα βήμα-βήμα, 24 ασκήσεις με λύσεις, γεννήτρια 14 τύπων με αυτόματο έλεγχο, quiz 22 ερωτήσεων
- PDF για εκτύπωση στον φάκελο `pdf/`

Στατικό site (ένα `index.html`), χωρίς build. Deploy στο Vercel: Import → Framework «Other» → Deploy.
